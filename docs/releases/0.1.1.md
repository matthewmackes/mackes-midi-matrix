# MACKES MIDI Matrix 0.1.1

Patch release adding scriptable route deployment to the stable MACKES MIDI Matrix
release line. Use `mackes-midi-matrix routes apply <routes.json>` to submit a
route document through the daemon's atomic, bounded validation boundary.

The release includes the complete `0.1.0` feature set: MIDI 1.0 and RTP-MIDI
transport contracts, deterministic routing with predicates, priorities, curves,
and cycle policy, MIDI Learn, scenes, setlists, monitoring, diagnostics,
backups, device profiles, and confirmation-gated device control.

Physical disconnect/reconnect, independent audio confirmation, and external-peer
network soak remain operator qualification activities. Unsupported or unverified
vendor operations remain disabled or read-only.
