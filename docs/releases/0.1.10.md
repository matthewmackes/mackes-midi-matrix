# MACKES MIDI Matrix 0.1.10

Release identity patch.

The workspace package version, CLI version output, daemon version output, and
release artifact version are aligned at `0.1.10`. The daemon accepts
`--version` and `version` without binding sockets or opening MIDI devices.

All `0.1.9` functionality remains included, including the connected-device TTY
tab strip. Physical writes and external hardware qualification remain
separately gated.
