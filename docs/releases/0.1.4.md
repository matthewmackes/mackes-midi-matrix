# MACKES MIDI Matrix 0.1.4

The Routing workspace filter cycle now covers all engine predicate families:
MIDI-number ranges, value ranges, realtime Clock, and masked SysEx matching.
The `f` shortcut remains bounded and returns to no filter after the complete cycle.

All `0.1.3` functionality remains included. Hardware, audio, reconnect, and
external-peer network qualification remain operator activities.
