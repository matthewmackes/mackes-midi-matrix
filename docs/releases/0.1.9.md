# MACKES MIDI Matrix 0.1.9

Multi-device TTY presentation patch release.

The primary mapping surface now presents a truthful connected MIDI rack header
and bounded device-tab strip, including connected/offline markers for visible
physical devices. This removes the previous single-Novation presentation when
multiple devices are attached.

All `0.1.8` functionality remains included. The full release gate covers
formatting, repository policy, dependency advisories, workspace tests, strict
Clippy, optimized routing throughput, hermetic integration, installer smoke,
and artifact checksum verification. Physical writes and external hardware
qualification remain separately gated.
