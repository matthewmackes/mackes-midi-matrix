# MACKES MIDI Matrix 0.1.0

This is the first public Fedora/Linux x86_64 release of MACKES MIDI Matrix.
It includes the operator CLI and TUI, daemon, MIDI 1.0 and RTP-MIDI transport
contracts, deterministic routing, MIDI Learn, scenes, setlists, monitoring,
diagnostics, backups, device profiles, and confirmation-gated device control.

## Included

- `mackes-midi-matrix` operator CLI and terminal interface
- `mackes-midi-matrixd` local daemon with bounded IPC and restart-safe state
- MIDI routing with channel/class filters, predicates, priorities, curves, and cycle policy
- MIDI Learn, scene planning/activation, setlists, monitor, diagnostics, and backups
- Eventide MicroPitch, Lexicon Reflex, M-VAVE IR Box, Launch Control XL, and conservative C.A.B. catalog entries
- Confirmation-gated profile controls and framed raw SysEx transmission
- Fedora installer, systemd service unit, provenance metadata, and checksum manifest

## Qualification and safety

The automated release gate covers formatting, locked dependencies, advisory scanning,
workspace tests, strict Clippy, routing throughput, hermetic integration scenarios,
and installer preflight. Physical disconnect/reconnect, independent audio confirmation,
and external-peer network soak remain operator qualification activities. Unsupported or
unverified vendor operations remain disabled or read-only. Device writes and raw SysEx
require explicit confirmation and a registered output destination.

Recreate the bundle with:

```bash
bash scripts/release-gate.sh
bash scripts/package-test-release.sh 0.1.0
```
