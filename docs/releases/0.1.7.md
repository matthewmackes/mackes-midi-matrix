# MACKES MIDI Matrix 0.1.7

Full-featured TTY workflow increment for connected MIDI controllers and
processor destinations.

This release includes:

- Launch Control XL Mk1 appliance-style faceplate vocabulary and operator panels.
- Authoritative connected-device and destination inventory in the primary TTY view.
- Live MIDI activity identity, value bars, and bounded activity pulse age.
- Destination-first parameter selection with parameter-aware route persistence.
- Daemon-owned, restart-safe one-step route Undo with rollback-safe persistence ordering.
- Local Fedora service installation and default startup verification.

The release gate covers formatting, policy/worklist checks, locked dependency
metadata, advisory scanning, workspace tests, strict Clippy, routing benchmark,
hermetic integration, installer smoke, and artifact checksum verification.

Physical disconnect/reconnect, physical LED appearance, independent RTP-MIDI
peer interoperability, and long-duration hardware/network soaks remain explicit
post-release qualification activities. Unsupported vendor capabilities remain
disabled or read-only and no physical test writes are implied by this release.
