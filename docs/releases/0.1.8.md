# MACKES MIDI Matrix 0.1.8

Operator observability patch release.

This release adds authoritative `route_undo_available` state to daemon
snapshots and sequenced events. The primary mapping surface now tells the
operator whether restart-safe route Undo is available or empty before an Undo
operation is requested.

The release includes all `0.1.7` controller faceplate, live activity,
destination/parameter mapping, and restart-safe route Undo features.

The full release gate covers formatting, policy/worklist checks, locked
dependency metadata, advisory scanning, workspace tests, strict Clippy,
optimized routing throughput, hermetic integration, installer smoke, and
artifact checksum verification. Physical writes remain separately gated and
are not implied by this release.
