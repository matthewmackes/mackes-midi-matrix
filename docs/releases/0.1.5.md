# MACKES MIDI Matrix 0.1.5

Safety patch release: the daemon panic command now sends All Sound Off (CC 120)
and All Notes Off (CC 123) on all 16 MIDI channels to every registered output.
The action remains available from the TUI, CLI, and mapped dashboard command
path and never redirects to an unregistered destination.

All `0.1.4` functionality remains included. Physical device, audio, reconnect,
and external-peer network qualification remain operator activities.
