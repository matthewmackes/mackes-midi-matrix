# MACKES MIDI Matrix 0.1.0-test.1

This is a Fedora 44 x86_64 testing and debugging build. It is intended for
operator evaluation, virtual-MIDI integration, and controlled hardware testing.

## Included

- `mackes-midi-matrix` operator CLI and terminal interface
- `mackes-midi-matrixd` local daemon
- Fedora installer and systemd service unit
- Installation and hardware-qualification documentation
- SHA-256 checksum manifest

## Verified operator workflow

- The CLI supports scene listing, safe scene planning, next/previous scene navigation,
  MIDI Learn capture requests, status, endpoint, route, monitor, profile, and backup queries.
- The TUI provides dashboard, MIDI Learn, Reflex, Eventide, and routing workspaces with
  number-key navigation, a persistent shortcut legend, scene controls, and panic access.
- The daemon persists accepted active-scene selections and uses signal-aware, bounded local
  IPC handling so normal and stalled-client shutdowns complete cleanly.

## Important limitations

- The retired C.A.B. device integration is not present.
- Physical disconnect/reconnect, independent audio confirmation, and external
  network soak remain post-release qualification activities.
- Device writes require the normal safety, verification, and confirmation gates.

## Verification

The source tree must pass `scripts/release-gate.sh` immediately before the
bundle is generated with `scripts/package-test-release.sh 0.1.0-test.1`.
