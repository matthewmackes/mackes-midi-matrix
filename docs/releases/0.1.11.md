# MACKES MIDI Matrix 0.1.11

Connected-device mapping qualification increment.

This release carries the authoritative physical-device inventory through daemon
snapshots and the TUI, including stable offline retention, bounded inventory
serialization, connected-device tabs, source and destination selection, profile
parameter browsing, live activity projection, route autosave/Undo, and bounded
audit visibility. The primary TUI uses a coherent ANSI-16 Linux terminal theme
and falls back truthfully for unsupported device profiles.

The workspace release gate verifies formatting, repository policy, dependency
advisories, workspace tests, strict Clippy, routing throughput, hermetic
integration, installer preflight, and release artifact checksums. Physical
device writes, independent RTP peers, and long-duration hardware/network soaks
remain explicit qualification activities.

Web Interface qualification also includes the Novation-first SVG surface, direct
per-device deep links, responsive 320/768/1440 captures, light-theme smoke, live
asset SHA-256 identity checks, and bounded read coalescing for Health/Mappings/
Snapshot bursts. The installed service passed the 1,000-cycle health probe and
the 100-request-per-endpoint feature soak. Native accessibility-tree capture,
injected-slow-feature browser fixtures, and the source-gated multi-destination
modifier contract remain open worklist items.
