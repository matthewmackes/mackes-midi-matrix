# MACKES MIDI Matrix 0.1.3

Patch release adding TUI authoring controls for the routing features already
implemented by the engine. In the Routing workspace, `r` cycles linear, square,
and square-root curves; `f` cycles common bounded number/value filter presets.
The selected route continues to display its effective state before save.

All `0.1.2` functionality remains included. Physical device, audio, reconnect,
and external-peer network qualification remain operator activities.
